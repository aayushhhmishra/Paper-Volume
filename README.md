# Paper-Volume

Paper Volume is a music discovery platform that empowers independent artists to share their work while helping listeners discover and support emerging talent.

The project is designed as a full-stack web application where users can explore artists and tracks, create an account, log in, and upload their own music.

<br>

## Features

- Discover independent music
- Explore artists and their profiles
- Browse available tracks
- Search for songs and artists
- Listen to uploaded songs
- View individual track profiles
- Create a user account
- Login and logout
- Personal user dashboard
- Upload MP3 songs
- Store track information in MongoDB
- Dynamically load uploaded tracks
- Password hashing using bcrypt

<br>

## Technologies Used

### Frontend

- HTML5
- CSS3
- JavaScript

### Backend

- Node.js
- Express.js

### Database

- MongoDB
- Mongoose

### Other Technologies

- Multer - File upload handling
- bcrypt - Password hashing
- Git & GitHub - Version control

<br>

## How It Works

Paper Volume follows a simple client-server architecture.

User
  ↓
Frontend (HTML, CSS, JavaScript)
  ↓
HTTP Requests
  ↓
Node.js + Express.js
  ↓
Mongoose
  ↓
MongoDB
